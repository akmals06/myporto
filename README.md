# Akmal Fadhlul Rohman — Personal Portfolio

An editorial scrapbook-style personal portfolio website built with React, TypeScript, Vite, and GSAP.

## Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Vanilla CSS, Design Tokens, Google Fonts (Anton, Kalam, Permanent Marker, Space Mono, Inter)
- **Icons**: Devicon CDN, Lucide Icons, Custom SVG Icons
- **Animations**: GSAP, Interactive Mouse Parallax, SVG midpoint displacement torn paper edges

## Features

- **Editorial Scrapbook Collage**: Handmade paper textures, polaroid frames, washi masking tapes, and hand-drawn doodles.
- **Sticky / Fixed Navbar**: Smooth navigation with animated hand-drawn blue oval indicator tracking the active section.
- **Tools I Use (Skills)**: Symmetrical 3-column layout organizing 36 technologies across Frontend & Web, Backend & Data, and Security & Tools.
- **Interactive Projects Showcase**: Swipeable scroll-snap carousel with detailed project cards and preview modals.
- **Research & Publication**: Dedicated academic research spotlight featuring the published JIKSI paper with abstract and journal links.
- **Certifications & Awards**: Verified credentials display with high-resolution document previews.
- **Responsive Design**: Optimized experience across all screen sizes, from mobile phones to ultrawide displays.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/akmals06/myporto.git

# Navigate to the project directory
cd myporto

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build

```bash
# Build the production bundle
npm run build

# Preview the production build
npm run preview
```
